Style guide

Vintage Lighting

Table lamps, sconces, library lamps, pleated shades, and warm vintage glow.

How this style works

Vintage Lighting works best when the room has one clear anchor and a few repeated materials. Start with brass stems, pleated shades, milk glass, then add smaller accents only after the room direction is clear.

Best materials

  • brass stems
  • pleated shades
  • milk glass
  • ceramic bases
  • library lamps

Common mistake

Check scale and shade condition before buying. A lamp can be beautiful and still too large.

What to shop first

  • One vintage lighting piece with visible character.
  • One framed artwork or mirror to set the mood.
  • Two small accessories that repeat the room palette.
  • One texture piece: velvet, linen, wood, glass, brass, or ceramic.
